# 07 术语表与进阶路线

> 最后一篇：把全文名词收拢成表，汇总各章思考题，并给出这个引擎继续长大的路线图。

## 1. 术语表

### 容器与码流

| 术语 | 含义 | 备注 |
| --- | --- | --- |
| 容器 (Container) | 把视频/音频/字幕打包成文件的格式 | mp4/mkv/mov/ts/flv/webm/avi/wav |
| 码流 (Bitstream) | 编码后的数据流 | H.264/H.265/AV1/AAC/MP3 |
| 编解码器 (Codec) | 编码/解码算法实现 | FFmpeg 内置 |
| 封装格式 (Muxer/Demuxer) | 打包/解包容器 | 本项目用 avformat 的 demuxer |

### 时间戳

| 术语 | 含义 | 备注 |
| --- | --- | --- |
| DTS | 解码时间戳 | 决定解码顺序 |
| PTS | 显示时间戳 | 决定播放顺序，B 帧让两者不同 |
| time_base | 时间戳单位 | `pts * time_base = 秒` |
| GOP | 关键帧组 | 以 I 帧开头，seek 的粒度 |

### 图像与像素

| 术语 | 含义 | 备注 |
| --- | --- | --- |
| YUV420P | 三个平面 Y/U/V | 软解常见输出 |
| NV12 | Y 平面 + UV 交织平面 | 硬解回读常见格式 |
| 色度抽样 | 4:2:0 等 | U/V 分辨率是 Y 的一半 |
| 色彩范围 | limited/full | 本项目用 BT.601 limited |

### 音频

| 术语 | 含义 |
| --- | --- |
| 采样率 | 每秒采样数（Hz），常见 44.1k/48k |
| 声道 | 单声道/立体声/多声道 |
| 位深 | 每个采样多少位，16/24/32(float) |
| WASAPI | Windows 音频 API（本项目输出后端） |
| 重采样 | 把采样率/声道/位深统一（libswresample） |

### 并发与同步

| 术语 | 含义 |
| --- | --- |
| 生产者-消费者 | 一个线程产数据，另一个消费，队列解耦 |
| 背压 | 队列满时生产者阻塞，速率被最慢环节钳制 |
| 条件变量 | 让线程"睡到有条件"的同步原语 |
| 主时钟 | 全局播放时间的权威来源（音频硬件时钟） |
| 丢帧 | 视频落后音频太多时主动跳过，追上节奏 |
| 单调时钟 | 不受系统时间调整影响的计时器（QPC） |

### 图形与系统

| 术语 | 含义 |
| --- | --- |
| 交换链 | DXGI 的前后台缓冲对，Present 翻转 |
| 像素着色器 | 逐像素执行的 GPU 程序（本项目做 YUV→RGB） |
| 硬件解码 | 用 GPU 解码单元代替 CPU 解码 |
| D3D11VA | Direct3D 11 视频加速接口（A/N/I 通用） |
| 单例注册表 | 用静态对象+注册函数管理可插拔后端 |

## 3. 进阶路线图

### 近期（引擎完善）

- **硬解 GPU 直通**：D3D11VA 帧不再拷回 CPU，渲染器直接消费显存纹理（省一次拷贝）；
- **更多硬解后端**：AMF（AMD）、QSV（Intel）、NVDEC（NVIDIA），注册表已就绪，一行一个；
- **精确 seek**：seek 后追帧到目标 pts 再显示，而不是从关键帧硬播；
- **seek 边界**：GIF/短文件、seek 到 EOF 的边界处理。

### 中期（引擎扩展）

- **采集模块**：屏幕采集（WGC）+ 音频采集（WASAPI loopback），管线从采集到渲染全通；
- **滤镜链**：在解码与渲染之间插入缩放/模糊/叠加，做成可插拔 Filter 接口；
- **流媒体**：MediaSource 支持 http(s) 输入，解封装线程处理网络 IO；
- **音量归一化**：按声道数/位深做响度处理。

### 后期（产品化：动态壁纸）

- **钉到桌面**：WorkerW/SHELLDLL_DefView 技巧，把渲染窗口放进桌面图标层后面；
- **多显示器**：每屏独立渲染实例；
- **网页嵌入**：WebView2 作为新的"媒体源"，与视频/图片/GIF 并列；
- **轮播与配置**：配置文件驱动播放列表，无人值守运行。
