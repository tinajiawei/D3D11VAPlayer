# 09 代码阅读地图（文件 → 函数 → 职责）

> 本文是"哪个文件、哪个函数在干嘛"的索引。建议顺序：docs/00 架构总览 → 本文 → 按需查 docs/01–08。
> 阅读主线：`ui/main.cpp`（入口）→ `player/media_player.cpp`（编排）→ `core`（基础）→ `media`（解封装/解码）→ `sync`（同步）→ `audio`（输出）→ `render`（显示）。

## 2. 播放器编排（src/player/）

`media_player.h/.cpp` 是心脏，六个线程围绕它转：

| 函数 | 线程 | 职责 |
| --- | --- | --- |
| `open` / `close` | UI | 建/拆管线：解码器、队列复位、音频初始化、线程启停 |
| `seek` | UI | 冻结主时钟 → flush 队列/解码器 → 重置设备缓冲 → 源跳转 → 发布新代数 |
| `set_speed` | UI | 更新倍率 + 80ms 去抖重开重采样器 + 冻结锚定 |
| `demux_loop` | 解封装 | `av_read_frame` 读包，按流分到两条包队列，包带 seek 代数 |
| `video_decode_loop` | 视频解码 | 弹包→解码→入帧队列；EOF 排空到底 |
| `audio_decode_loop` | 音频解码 | 弹包→解码→重采样→写环形缓冲；变速重开、精确 seek 丢帧、锚定 |
| `render_loop` | 渲染 | 弹帧→与主时钟比（丢帧/等待）→D3D11 上屏→画面板 |

关键状态：`seek_gen_`（代数，防旧包/旧帧污染）、`video/audio_flush_requested_`（各自消费）、`audio_resampler_reopen_`、`seek_target_`/`discard_until_target_`（精确 seek）。

## 4. 解封装与解码（src/media/）

| 文件 | 关键函数 | 职责 |
| --- | --- | --- |
| `media_source.cpp` | `open/read_packet/seek` | avformat 封装；`io_mutex_` 串行化读包与 seek |
| `packet_queue.cpp` | `push/pop/flush/abort/reset` | 有界包队列；每包记录入队时的 seek 代数（`gens_`） |

## 5. 同步（src/sync/）

`sync_engine.cpp`：

| 函数 | 职责 |
| --- | --- |
| `master_clock` | 音频可听位置×倍率+偏移；seek/变速后冻结，0.5s 超时兜底 |
| `video_delay` | 视频帧等待时长（内容秒→墙钟秒，÷倍率） |
| `set_speed` | 保持主时钟连续地切换倍率 |
| `seek` | 把主时钟设到目标点 |
| `freeze_until_audio` / `audio_resume` | 等待第一帧新音频写入后按"写入位置"锚定（精确对齐） |
| `align_to_video` | 首帧对齐 |

## 6. 音频（src/audio/）

| 文件 | 关键函数 | 职责 |
| --- | --- | --- |
| `audio_output.cpp` | `init_attempt/try_device` | 找可用端点：默认→枚举，跳过免提端点，事件失败用全新 client + 轮询 |
| | `run_loop` | WASAPI 回调线程：读环→写设备缓冲，写失败自动重置自愈 |

| `audio_resampler.cpp` | `open/convert/drain` | libswresample 封装；输出率 = 设备采样率 ÷ 倍率（docs/10） |

## 7. 渲染（src/render/）

`d3d11_renderer.cpp`：`init`（适配器/交换链）、`draw_frame`（YUV→RGB 着色器 + letterbox + 旋转）、`set_pending_size/apply_pending_size`（ResizeBuffers）、`present_swapchain`。

## 8. 线程与阻塞点一览

| 线程 | 入口 | 主要阻塞点 |
| --- | --- | --- |
| 主线程 | `wmain` | 消息循环 |
| 解封装 | `demux_loop` | 包队列满、EOF 挂起（等 seek 代数） |
| 视频解码 | `video_decode_loop` | 包队列空、帧队列满 |
| 音频解码 | `audio_decode_loop` | 包队列空、环形缓冲满（背压） |
| 渲染 | `render_loop` | 帧间隔等待（≤200ms 分片） |
| WASAPI | `AudioOutput::run_loop` | 事件/轮询等待（100ms/10ms） |

## 9. 调试与回归入口

- `tools/acceptance.ps1`：29 场景自动验收（格式/同步/软硬解），结果 `tools/acceptance_results.md`
- `tools/wasapi_probe.cpp`：逐端点打印混音格式与初始化结果（扬声器排查）
- 命令行参数：`--hw --seek --eof-seek --speed --pause-test --device --reopen --wallpaper --debug`
- 日志关键词：`[sync]`（时钟）、`[audio]`（WASAPI）、`[adec]`（音频 pts 速率）、`DRAW_MS`（渲染耗时）

## 10. 解码器插件化（plugin DLL）

- 插件 ABI：`src/media/decoder_plugin.h`（导出宏 + `DecoderRegistry` + `me_register_decoders`）；
- 插件：`plugin\1\decoder_sw.dll`、`plugin\1\decoder_d3d11va.dll`，由 `DecoderFactory` 启动时 LoadLibrary 加载；
- 新增后端 = 新插件 DLL（如 decoder_amf.dll），播放器零改动；
- `1` 是插件接口版本号，升接口换目录，避免 ABI 混乱。

## 11. 模块化现状

- `media_engine.dll`：引擎主体（core+media+sync+audio+render+player），导出窄 C API（api/me_api.h）；
- `plugin\1\*.dll`：解码器插件（sw / d3d11va），由引擎启动时加载；
- `media_player_app.exe`：UI 宿主（窗口 + ImGui），只调用 C API，不链接引擎内部；
- 静态库 `media_engine_core` 保留给单元测试使用。
