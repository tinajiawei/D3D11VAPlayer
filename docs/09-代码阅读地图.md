## 0. 模块接口层（src/api/）

> 二期模块化的"接口先行"层：渲染/音频/同步各自只依赖抽象、不依赖具体实现（参考 515 的 IRDMediaRender / IAVSyn 思路）。

| 文件 | 职责 |
| --- | --- |
| `irenderer.h` | `IRenderer`：init/shutdown/draw_frame/present/device/context；`D3D11Renderer` 实现，未来 WebView2/无头渲染也实现它 |
| `iaudio_sink.h` | `IAudioSink`：init/start/write/时钟/设备切换；`AudioOutput`（WASAPI）实现 |
| `isync_engine.h` | `ISyncEngine`：master_clock/video_delay/seek/freeze/audio_resume；`SyncEngine` 实现 |

`MediaPlayer` 现在只持有 `IRenderer*`、`unique_ptr<ISyncEngine>`、`IAudioSink*`，换后端不动编排层；解码器侧同类抽象见 docs/04（`IDecoder` + 插件 DLL）。

## 2. 播放器编排（src/player/）

`media_player.h/.cpp` 是心脏，六个线程围绕它转：

| 函数 | 线程 | 职责 |
| --- | --- | --- |
| `open` / `close` | UI | 建/拆管线：解码器、队列复位、音频初始化、线程启停 |
| `seek` | UI | 冻结主时钟 → flush 队列/解码器 → 重置设备缓冲 → 源跳转 → 发布新代数 |
| `set_speed` | UI | 更新倍率 + 80ms 去抖重开重采样器 + 冻结锚定 |
| `demux_loop` | 解封装 | `av_read_frame` 读包，按流分到两条包队列，包带 seek 代数 |
| `video_decode_loop` | 视频解码 | 弹包→解码→入帧队列；EOF 排空到底 |
| `audio_decode_loop` | 音频解码 | 弹包→解码→重采样→写环形缓冲；变速重开、精确 seek 丢帧、锚定 |
| `render_loop` | 渲染 | 弹帧→与主时钟比（丢帧/等待）→D3D11 上屏→画面板 |

关键状态：`seek_gen_`（代数，防旧包/旧帧污染）、`video/audio_flush_requested_`（各自消费）、`audio_resampler_reopen_`、`seek_target_`/`discard_until_target_`（精确 seek）。

## 5. 同步（src/sync/）

| 函数 | 职责 |

| `video_delay` | 视频帧等待时长（内容秒→墙钟秒，÷倍率） |

## 8. 线程与阻塞点一览

| 线程 | 入口 | 主要阻塞点 |
| --- | --- | --- |
| 主线程 | `wmain` | 消息循环 |
| 解封装 | `demux_loop` | 包队列满、EOF 挂起（等 seek 代数） |

## 10. 解码器插件化（plugin DLL）

- 插件 ABI：`src/media/decoder_plugin.h`（导出宏 + `DecoderRegistry` + `me_register_decoders`）；
- 插件：`plugin\1\decoder_sw.dll`、`plugin\1\decoder_d3d11va.dll`，由 `DecoderFactory` 启动时 LoadLibrary 加载；
- 新增后端 = 新插件 DLL（如 decoder_amf.dll），播放器零改动；
- `1` 是插件接口版本号，升接口换目录，避免 ABI 混乱。

## 11. 模块化现状

- `media_engine.dll`：引擎主体（core+media+sync+audio+render+player），导出窄 C API（api/me_api.h）；
- `plugin\1\*.dll`：解码器插件（sw / d3d11va），由引擎启动时加载；
- `media_player_app.exe`：UI 宿主（窗口 + ImGui），只调用 C API，不链接引擎内部；
- 静态库 `media_engine_core` 保留给单元测试使用。
