### 三、软硬解对比（6/6 PASS，含降级验证）
| 场景 | 解码器选择 | 绘制 | 结论 |
| --- | --- | --- | --- |
| H.264 软解 | sw | 138 | PASS |
| H.264 --hw | sw（d3d11va 本机不可用自动降级） | 138 | 降级路径 PASS |
| HEVC 软解 | sw | 138 | PASS |
| HEVC --hw | sw（降级） | 138 | 降级路径 PASS |
| AV1 软解 | sw | 96 | PASS |
| AV1 --hw | sw（降级） | 96 | 降级路径 PASS |

**硬解结论（已修复并激活）**：
- H.264 / HEVC：`--hw` 实测 `解码器选择: d3d11va`，日志出现 `D3D11VA 硬解开启`，帧格式为 d3d11（GPU 解码 → 拷回 NV12 统一渲染）；
- AV1：RX 6700 XT（RDNA2）无 AV1 硬解单元，自动降级软解——属预期行为；
- 根因：旧代码在 `avcodec_open2` 后立刻检查 `ctx_->pix_fmt`，而 FFmpeg 要到**第一帧**才把 pix_fmt 切成 d3d11，导致硬解永远被误判为不支持。改为 `avcodec_get_hw_config` 校验 + 首帧软帧透传兜底后激活。

## 2.5 扬声器诊断（wasapi_probe）

新增独立工具 `tools/wasapi_probe.cpp`（`build\src\wasapi_probe.exe`），逐个端点打印名称/默认标志/混音格式/两种初始化结果。诊断结论：
- 系统默认端点是 `Tmall Genie BOOM Hands-Free AG Audio`（8000Hz 免提电话端点）——音乐播放默认走它必然无声/劣质；
- Tmall Stereo 端点的引擎首选格式（48k 事件驱动）返回 0x88890008，但**混音格式 + 轮询 + 全新 client 可以成功**；
- 根因一：引擎的 `IsFormatSupported` 预检会把这个蓝牙端点置为失效态，后续全新 client 也失败；去掉预检、直接让 Initialize 报错再走回退（与探针同序列）后成功；
- 根因二：事件模式失败后复用了同一个已失效的 client，必须重新 Activate 全新 IAudioClient 再试轮询；
- 修复：枚举/默认/回退/切换四路径统一过滤 Hands-Free/AG Audio 端点，避免下拉框出现电话端点。
实测：默认播放自动选中 `耳机 (Tmall Genie BOOM(11:04) Stereo)`（44100Hz 轮询），切换 #2 成功切到 XIBERIA S21 MAX。

## 3. 本轮修复清单
## 3. 本轮修复清单（验收驱动）

1. **seek 后音画恒定偏移**：主时钟冻结 + 第一帧音频"写入位置锚定"（docs/06 坑 AJ）；
2. **快速来回拖动错锚**：冻结/锚定绑定 seek 代数，旧 seek 的帧不能锚定新 seek（坑 AK）；
3. **解封装推包跨 seek**：PacketQueue 给每个包记录入队代数，旧包解码前丢弃（坑 AL）；
4. **队列清空时代数不同步**：flush/abort/reset 三处同步清 `gens_`（坑 AM）；
5. **冻结可能被管线背压饿死**：0.5s 超时兜底，杜绝永久冻结（坑 AN，见下）；
6. **EOF 排空未完成**：`avcodec_send_packet` 在排空态收到新包返回 AVERROR_EOF，解码循环排空到底 + 包装层防御性丢弃（坑 AO，见下）；
7. **设备名/枚举器跨线程竞争**：`device_name()` 改加锁拷贝，`enumerator_` 读写加锁；
8. **增量构建 ABI 错位**（重要教训）：改头文件布局后必须 `--clean-first` 全量重建，否则出现 `device_names()` 读错对象偏移的 0xC0000005 崩溃。

## 4. 已知限制（一期内接受）

- **动画 WebP 不支持**：FFmpeg webp 解码器跳过 ANMF 动画块；样例已改为静态 WebP，动画 WebP 列入二期；
- ~~向后 seek 落在前一关键帧~~（已实现精确 seek：音频丢弃目标点之前的帧，跳转即停在目标点）；
- **切换设备可能短暂中断音频**：冻结 0.5s 超时后回到正常时钟，音频在管线恢复后自愈；
- **本机 IAudioClock 不可靠**：回退"已写帧数 − 缓冲水位"计数时钟（更准确）；
- **AV1 无硬解**：RX 6700 XT（RDNA2）无 AV1 硬解单元，自动降级软解（H.264/HEVC 已激活）。
